# COUNTRIES SEARCH APPLICATION

A web application for viewing information about countries around the world, created using React, TypeScript, Ant Design, and the REST Countries API.

## Features

*   **List of Countries:** Displays a list of all countries in the world with their flags.
*   **Search:** Ability to search for countries by name.
*   **Pagination:** Paginated display of the country list for easy navigation.
*   **Detailed Information:** Clicking on a country opens a separate page with detailed information:
    *   Official Name
    *   Flag
    *   Capital
    *   Population
    *   Area
    *   Languages
    *   Currencies
    *   Country Code (CCA3)
*   **Responsiveness:** Basic responsiveness of the interface for different screen sizes.

## Technologies

*   React (v18+)
*   TypeScript
*   React Router DOM (v6+)
*   Ant Design (v5+)
*   Axios
*   REST Countries API (v3.1)
*   Create React App

## COMPILATION

1.  **CLONE:**
    ```bash
    git clone <Your repository URL>
    cd countries-app
    ```

2.  **INSTALL DEPENDENCIES:**
    ```bash
    npm install
    ```
    *Or, if you use Yarn:*
    ```bash
    yarn install
    ```

3.  **RUN DEV MODE**
    ```bash
    npm start
    ```
    *Or:*
    ```bash
    yarn start
    ```
    Input in address bar [http://localhost:3000](http://localhost:3000).
